MechLex 10.1.0 — דוח שערי איכות, עריכה חזותית וגיבוי Word
=========================================

היקף הבדיקה
-----------
הדוח מתייחס למהדורת Desktop Offline RTL המקומית. הבדיקות בוצעו על עותק מבודד של נתוני הדפדפן,
ללא העלאת קבצים וללא פנייה לשירות אינטרנט חיצוני.

שער איכות סטטי
---------------
- תחביר JavaScript נבדק לכל קובצי היישום ולשני קובצי בדיקות הדפדפן/מבנה.
- קיום קובצי החובה, נתיבי HTML, סדר טעינת הסקריפטים ומזהי HTML ייחודיים נבדקו אוטומטית.
- כל הפניות ה-ID הקבועות מתוך JavaScript נמצאו ב-HTML.
- ארבעת החלונות המודאליים נבדקו למצב פתיחה סגור ולשימוש במנגנון המודאלי המרכזי.
- קטלוג הבסיס נבדק למזהים, קודים וקידומות ייחודיים, היררכיה תקינה וקישורי related תקפים.
- שני גיבויי JSON ההתחלתיים נקראו בהצלחה ונמצאו לא ריקים.
- גרסת app.js, כותרת HTML, package.json, VERSION, README ו-CHANGELOG נבדקה לעקביות 10.1.0.
- המניפסט נבדק הן לכיסוי כל קובצי החובה והן להתאמת SHA-256 של כל קובץ.

שער דפדפן אוטומטי
------------------
- האתחול, הכותרת, טעינת הקטלוג וזמן העלייה נבדקו ב-Edge/Chromium בפרופיל מבודד.
- פתיחת מושג במקלדת, מלכודת פוקוס, Escape, החזרת פוקוס ו-aria-hidden נבדקו בפועל.
- הורדת PNG ו-JPEG נבדקה; שני הקבצים נמצאו לא ריקים ושונים זה מזה.
- מועדפים ומצב למידה נבדקו לאחר טעינה מחדש.
- ייצוא מצב אישי ל-JSON נבדק.
- PIN שגוי, Content Admin והפרדת הרשאות Super Admin נבדקו.
- יצירה ומחיקה של מושג, ניקוי HTML מסוכן ושלמות הקטלוג נבדקו.
- גיבוי מלא נבדק לקיום checksum ולתקפותו; גיבוי ששונה בכוונה נדחה.
- שמות נגישים לכל הפקדים הגלויים נבדקו אוטומטית.
- נבדק שאין גלילה אופקית ברוחב 390, 768 ו-1440 פיקסלים.
- prefers-reduced-motion נבדק בפועל.
- לא נמצאו שגיאות Console, שגיאות עמוד, בקשות HTTP כושלות או בקשות חיצוניות.
- פתיחה וסגירה של חלון מושג נבדקו גם לאזהרת Blocked aria-hidden; לא התקבלו אזהרות לאחר התיקון.
- תוצאה: 48 הצהרות קבלה עברו.

בדיקות השרת המקומי
-------------------
- GET ו-HEAD מוחזרים בהצלחה; שיטות אחרות נדחות ב-405 עם כותרת Allow.
- ניסיון מעבר מחוץ לתיקיית הפרויקט נדחה ב-403.
- השרת מאזין ל-127.0.0.1 בלבד ומוסיף CSP, nosniff, Referrer-Policy ו-Permissions-Policy.
- מופע MechLex קיים מזוהה; אם תוכנה אחרת תופסת את 8765 נבחר פורט פנוי סמוך.

בדיקות UI ונגישות חזותיות
-------------------------
- נבדקו מסך הבית, מסך תחום, חלון מושג ומרכז הניהול בתצוגת מחשב.
- נבדקה תצוגת מובייל ברוחב 390 פיקסלים: התפריט מוסתר מחוץ למסך ואין חיתוך אופקי.
- נבדקה גם הרזולוציה 1512×727 מהדיווח: טקסט ה-Hero שומר מרווח עליון ותחתון ואינו נחתך.
- חלונות המושג והניהול נבדקו לאחר סיום אנימציה ולא נמצאו חפיפה, חיתוך או טקסט מוסתר.
- כיוון RTL, טבעות פוקוס, שמות שדות וניגודיות תפעולית נמצאו תקינים.

אבחון אזהרת content.js
----------------------
- אין בפרויקט קובץ content.js ואין בקוד שימוש ב-unload או beforeunload.
- האזהרה Permissions policy violation: unload נובעת מקוד שמוזרק על ידי תוסף דפדפן.
- לא הופעלה הרשאת unload כדי להשתיק את האזהרה, משום שהאירוע מיושן ופוגע ב-back/forward cache.

בדיקות גיבוי Word
-----------------
- תיקיית "גיבוי וורד" משמרת את מבנה תיקיות המקור.
- לכל קובץ מקור טקסטואלי נוצר מסמך מקביל בשם המקור בתוספת .docx.
- מסמכי Word אינם כוללים כותרות הסבר, מספור עמודים או תוכן שאינו קיים במקור.
- תוכן כל מסמך הושווה אוטומטית למקור ונדרש להיות זהה שורה מול שורה.
- כל DOCX נפתח מחדש ונבדק מבנית: עמוד לרוחב, גופן Consolas, מספר פסקאות תואם, ללא כותרות עליונות/תחתונות,
  טבלאות, תמונות, הערות, מאקרו או קישורים חיצוניים.
- רינדור DOCX ל-PNG לא בוצע בסביבה זו משום שלא מותקנים LibreOffice או Microsoft Word. זהו פער אימות מתועד בלבד;
  המסמכים הם עותקי קוד פשוטים ללא רכיבי פריסה מורכבים, וכל התוכן והמבנה שלהם אומתו אוטומטית.

מגבלות אבטחה מכוונות
--------------------
- קודי האדמין מיועדים להפרדת תפקידים בכלי אופליין מקומי; הם אינם הצפנה או מערכת זיהוי ארגונית.
- אין לשמור במילון מידע מסווג או רגיש ללא מעטפת אבטחה חיצונית ואישור מתאים.
- גיבוי Word הוא עותק תיעודי בלבד. קובצי המקור הרגילים הם מקור האמת להרצה ולפיתוח.

מסקנת שחרור
-----------
הגרסה מוכנה לשימוש אופליין מקומי בכפוף למגבלות האבטחה המתועדות. שער השחרור דורש מעבר מלא של
הבדיקה הסטטית, 48 הצהרות הדפדפן, אימות השרת, התאמת מניפסט וגיבוי Word מדויק שעבר אימות מבני.
