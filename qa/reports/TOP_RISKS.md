# Top Risks

1. **Shared data corruption or misinterpretation:** active state is an unsigned legacy performance fixture.
2. **Privilege escalation:** Super Admin is a UI state, not an enforced authorization boundary.
3. **Split-brain:** failed initial sync can lead to local-only saves.
4. **False recovery:** browser restore can succeed locally without repairing the shared source.
5. **Capacity failure:** Base64 whole-state persistence cannot reliably reload the 15MB case.
6. **Unstable polling:** Edge treats the 304 polling response as an aborted request.
7. **Concurrent edit loss:** stale-write protection rejects one user but offers no merge/preservation flow.
8. **Wrong-instance reuse:** launcher may attach to an unrelated server on port 8765.
9. **Incomplete disaster backup:** external images are outside the JSON backup.
10. **Unproven deployment permissions:** real Windows ACL/SMB behavior was not tested.
